velog 글쓰기처럼 헤더 없는 전체 화면에 에디터, 미리보기, 서식 툴바를 만들었다.

## 화면 구성

- 왼쪽: 제목, 짧고 굵은 구분선, 툴바, 마크다운 에디터(CodeMirror 6)
- 오른쪽: 미리보기 (768px 미만에서는 숨김)
- 하단: 나가기 / 저장 (저장은 DB 연결 후)

`app/write/`를 `(main)` 그룹 **밖에** 둬서 헤더가 붙지 않는다.

## 툴바

- [x] 제목 H1~H4 (같은 버튼 다시 누르면 제거)
- [x] 굵게, 기울임, 취소선
- [x] 인용, 링크, 이미지 주소, 코드 블록
- [ ] 이미지 업로드 (S3 단계에서)
- [ ] 단축키 (Ctrl+B 등)

## 설계

| 파일                 | 역할                                                   |
| -------------------- | ------------------------------------------------------ |
| `editor-commands.ts` | 텍스트 조작 로직 (화면과 분리 → 테스트, 단축키 재사용) |
| `editor-toolbar.tsx` | 버튼 UI. 배열 데이터로 `map`                           |

## 배운 것

- **`useRef`로 외부 라이브러리 인스턴스 잡기**: 툴바가 에디터를 조작할 수 있게
- **명령형 API**: CodeMirror는 `view.dispatch({ changes })`로 변경을 요청한다
- **CodeMirror는 Tailwind 대신 `EditorView.theme`**: 내부 DOM에 클래스가 닿지 않는다
- 링크와 이미지는 `!` 하나 차이라 **공통 함수** `insertUrlSyntax`로 합쳤다

## 수정 모드

- `/write` → 새 노트, `/write?id=1` → 1번 수정
- 없는 id나 여러 id는 **404**. 새 노트로 열면 "수정 중"이라 착각하고 노트가 하나 더 생긴다
