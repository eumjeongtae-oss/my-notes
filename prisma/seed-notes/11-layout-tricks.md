실무에서 자주 쓰는 레이아웃 트릭 두 가지: 음수 마진과 flex의 min-h-0.

## 1. 음수 마진 트릭

hover 배경은 넓게, 글자 위치는 그대로 두고 싶을 때.

```html
<a class="-mx-4 px-4"></a>
```

- `px-4`: 안쪽 여백 16px → 배경이 글자보다 넓어진다
- `-mx-4`: 바깥으로 16px 당긴다 → 글자 위치는 제자리

두 값이 상쇄돼서 **글자는 제목과 줄이 맞고, 배경만 양옆으로 넓어진다.**

⚠️ 컨테이너 여백보다 크게 당기면 모바일에서 가로 스크롤이 생긴다.

에디터 커서가 줄 맨 앞에서 잘릴 때도 같은 트릭을 썼다 (`padding-left: 2px` + `-ml-0.5`).

## 2. flex와 min-h-0

글쓰기 화면: 위는 에디터(늘어남), 아래는 하단 바(고정).

```
flex h-full flex-col
  min-h-0 flex-1    ← 에디터: 남은 높이를 다 차지
  h-16 shrink-0     ← 하단 바: 64px 고정
```

**flex 자식은 기본적으로 내용보다 작아지지 않는다.**
`min-h-0`이 없으면 글이 길어질 때 에디터가 화면 밖으로 늘어나고 하단 바가 밀려난다.

## 외부 라이브러리 스타일을 덮어쓸 때

`padding: 0` 하나 바꿨더니 커서가 안 보이는 문제가 생겼다.
라이브러리가 **그 값에 기대고 있는 게 있는지** 조심한다.
