노션식 사이드바를 걷어내고 velog처럼 카드 목록 홈과 읽기 페이지를 만들었다.

## 만든 것

- **공통 헤더**: 로고 아이콘 + "새 노트" 버튼
- **홈**: 목록형(기본) / 카드형 보기, 최신순 / 오래된순 정렬
- **빈 화면**: 직접 그린 SVG 일러스트 + 안내 문구 + "첫 노트 쓰기" 버튼
- **읽기 페이지**: 가운데 정렬 본문, 큰 제목, 날짜, 수정 링크

## 디자인하면서 배운 것

### Empty state

노트가 없을 때 아이콘 하나만 두면 허전하다.
**일러스트 + 안내 문구 + 다음 행동 버튼** 조합이 실무에서 흔한 패턴이다.

### 같은 앱 안에서는 반응을 통일한다

카드형은 hover하면 떠오르는데 목록형은 밑줄만 생겨서 어색했다.
목록형도 **카드가 길어진 모양**으로 바꾸고 같은 hover 효과를 줬다.

### 비슷한 컴포넌트는 variant로 합친다

```tsx
<NoteCard note={note} />                 // 카드형
<NoteCard note={note} variant="list" />  // 목록형
```

차이(글자 크기, 요약 길이)는 `styles` 객체 한 곳에 모았다.

## 데이터 접근을 한 파일에 모은 이유

화면은 `src/lib/notes.ts`의 `getNotes()`, `getNote()`만 호출한다.
가짜 데이터를 DB로 바꿀 때 **이 파일만 고치면** 화면 코드는 그대로 둘 수 있다.
