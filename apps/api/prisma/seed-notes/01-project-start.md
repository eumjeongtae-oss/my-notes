투두리스트로 시작했다가 velog 형식의 개인 노트 앱으로 방향을 정했다.

## 목표

- Next.js, Tailwind를 처음 써보면서 익히기
- 백엔드(DB, API, 로그인)를 처음부터 배우기
- **실무와 같은 방식**으로 작업해서 바로 실무에 투입될 수 있게 하기

## 방향이 바뀐 과정

1. 투두리스트 → 블로그(velog 모티브)
2. 블로그 → 노션처럼 **나만 보는** 노트
3. 노션식 사이드바 → 다시 **velog 형식의 화면** + 나만 보는 노트

> 처음부터 완벽하게 정하지 않아도 된다. 만들면서 방향을 다듬는 것도 실무의 일부다.

## 정한 기술

| 역할       | 선택                              |
| ---------- | --------------------------------- |
| 프레임워크 | Next.js 16 (App Router)           |
| 스타일     | Tailwind CSS 4                    |
| DB / ORM   | MySQL 8 + Prisma (팀 스택과 같게) |
| 배포       | AWS EC2 + Docker, 이미지는 S3     |
